The single-view user references guided appearance; no third-party mesh was copied.

The Body Map now uses image-brain.glb, image-heart.glb, image-liver.glb,
image-dna.glb and image-leg.glb, built by image-to-3d.py from the five reference
images in source/ that the project owner supplied for this purpose. The images are
used as the models' textures; the meshes are inflated from their outlines (a
rounded estimate from a single view, not a scan). The reference-*.glb files are
kept but no longer used.
